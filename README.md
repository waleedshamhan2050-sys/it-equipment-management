# نظام إدارة معدات تكنولوجيا المعلومات (IT Equipment Management System)

## نظرة عامة على المشروع

هذا المشروع عبارة عن نظام ويب بسيط لإدارة معدات تكنولوجيا المعلومات، مصمم خصيصًا لطلاب السنة الثانية في تخصصات تكنولوجيا المعلومات. يهدف النظام إلى محاكاة بيئة إدارة الأصول في الشركات، مما يتيح للمستخدمين تتبع المعدات، إدارة طلبات الصيانة، وعرض تحديثات حالة المعدات بطريقة فعالة ومنظمة.

تم تطوير هذا المشروع باستخدام تقنيات الويب الأساسية (HTML, CSS, JavaScript) ليكون سهل الفهم والتعديل، مع التركيز على إظهار المفاهيم الأساسية لتطوير تطبيقات الويب وإدارة البيانات من جانب العميل (Client-side).

## الميزات الرئيسية

يتضمن النظام الميزات التالية:

*   **تتبع المعدات**: إضافة، عرض، وتعديل تفاصيل المعدات مثل الاسم، النوع، الرقم التسلسلي، والموقع.
*   **إدارة طلبات الصيانة**: تسجيل طلبات الصيانة للمعدات، تحديد نوع الصيانة، الأولوية، وتتبع حالتها.
*   **تحديثات حالة المعدات**: عرض الحالة الحالية لكل معدة (نشطة، معطلة، تحت الصيانة) وتحديثها.
*   **لوحة تحكم تفاعلية**: ملخص سريع لأعداد المعدات وحالاتها، بالإضافة إلى عدد طلبات الصيانة.
*   **تقارير مبسطة**: إمكانية توليد تقارير عن المعدات وطلبات الصيانة وحالة النظام.
*   **تخزين البيانات محليًا**: يتم حفظ جميع البيانات في `localStorage` الخاص بالمتصفح، مما يوفر تجربة مستخدم مستمرة دون الحاجة لقاعدة بيانات خلفية.

## التقنيات المستخدمة

*   **HTML5**: لبناء هيكل صفحات الويب.
*   **CSS3**: لتصميم وتنسيق واجهة المستخدم، مع التركيز على الاستجابة (Responsive Design).
*   **JavaScript (ES6+)**: لإضافة التفاعل، إدارة البيانات، ومنطق التطبيق.
*   **Canvas API**: لرسم الرسوم البيانية البسيطة في قسم حالة النظام.

## المهارات المكتسبة من هذا المشروع

من خلال تطوير هذا المشروع، سيكتسب الطالب المهارات التالية:

*   **أساسيات تطوير الويب**: فهم كيفية عمل HTML, CSS, و JavaScript معًا لبناء تطبيق ويب كامل.
*   **إدارة DOM**: التلاعب بعناصر HTML ديناميكيًا باستخدام JavaScript.
*   **تخزين البيانات من جانب العميل**: استخدام `localStorage` لتخزين واسترجاع البيانات محليًا في المتصفح.
*   **بناء واجهات المستخدم (UI)**: تصميم واجهة مستخدم بديهية وسهلة الاستخدام.
*   **معالجة الأحداث (Event Handling)**: الاستجابة لتفاعلات المستخدم مثل النقر على الأزرار وإرسال النماذج.
*   **تنظيم الكود**: كتابة كود نظيف، منظم، ومعلق جيدًا باستخدام مبادئ البرمجة كائنية التوجه (OOP) البسيطة في JavaScript.
*   **تصميم الرسوم البيانية**: استخدام Canvas API لتمثيل البيانات بصريًا.
*   **التعامل مع النماذج**: جمع والتحقق من صحة بيانات المستخدم من خلال نماذج HTML.

## كيفية تشغيل المشروع

لتشغيل هذا المشروع على جهازك المحلي، اتبع الخطوات التالية:

1.  **استنساخ المستودع (Clone the repository)**:
    ```bash
    git clone https://github.com/your-username/it-equipment-management.git
    ```
    (ملاحظة: ستحتاج إلى استبدال `your-username` باسم المستخدم الخاص بك على GitHub بعد رفع المشروع.)

2.  **الانتقال إلى مجلد المشروع**:
    ```bash
    cd it-equipment-management
    ```

3.  **فتح الملف في المتصفح**: 
    افتح الملف `src/index.html` مباشرة في متصفح الويب الخاص بك. يمكنك القيام بذلك عن طريق النقر المزدوج على الملف، أو سحبه وإفلاته في نافذة المتصفح، أو استخدام أمر مثل:
    ```bash
    open src/index.html # لنظام macOS
    start src/index.html # لنظام Windows
    xdg-open src/index.html # لنظام Linux
    ```

    بدلاً من ذلك، يمكنك استخدام إضافة خادم محلي (مثل 
Live Server في VS Code) لفتح الملف، مما يتيح لك رؤية التغييرات تلقائيًا أثناء التطوير.
